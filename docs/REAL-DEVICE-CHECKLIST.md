# AI-Plantgraphy PWA 実機確認チェックリスト

作成日: 2026-05-19

## 目的

Android Chrome で `インストール + APIキー入力` だけで主要機能が使えるか確認する。

確認対象:

- GitHub Pages で公開された PWA
- Android Chrome
- Gemini API キーを設定した状態

## 事前準備

- Android Chrome を最新版にする
- Gemini API キーを用意する
- テスト用の植物写真を 1〜3 枚用意する
- 可能なら通信が安定した場所で実施する

## 1. 初回起動とインストール

手順:

1. GitHub Pages のURLをAndroid Chromeで開く
2. ヘッダーに `ブラウザ表示`、`オンライン`、`API キー未設定` が表示されることを確認する
3. Chromeメニュー、または画面のインストールボタンからホーム画面へ追加する
4. ホーム画面アイコンから起動する

期待結果:

- アプリとして起動できる
- ヘッダーが `インストール済み` になる
- 画面遷移で404にならない

## 2. APIキーと設定

手順:

1. `設定` を開く
2. Gemini API キーを入力する
3. 利用モデルを選ぶ
4. 場所ラベルを追加する
5. アプリを閉じて再起動する

期待結果:

- APIキー設定済み表示になる
- モデルと場所ラベルが保持される
- 診断欄に保存容量、画像件数、バックアップ対象件数、ログ件数が表示される

## 3. 観察追加

手順:

1. `追加` を開く
2. カメラ撮影、または写真選択で画像を追加する
3. 画像プレビューから 1〜3 枚を選ぶ
4. 撮影日が自動入力されていることを確認する
5. 場所ラベルとメモを入力する
6. 観察を保存する

期待結果:

- 選択画像がプレビューされる
- 画像を削除できる
- 観察が保存され、解析が始まる
- 解析中は経過秒が表示される

## 4. 観察解析

手順:

1. 解析中の観察詳細を開く
2. 解析完了まで待つ
3. `観察`、`確認待ち`、`設定 > ログ` を確認する

期待結果:

- 解析完了後に経過秒が止まる
- 候補、信頼度、見えている特徴、不確実な点、JSONが表示される
- 高信頼なら図鑑生成へ進む
- 低信頼または失敗なら確認待ちに表示される
- 設定画面のログに解析開始/完了/失敗が残る

## 5. 強制停止

手順:

1. 観察解析中、または図鑑生成中に停止ボタンを押す
2. 詳細画面と確認待ちを確認する
3. 設定画面のログを確認する

期待結果:

- 状態が失敗または停止扱いになる
- 後から返ってきた解析結果で上書きされない
- 確認待ちに表示される
- 停止ログが残る

## 6. 図鑑生成

手順:

1. `図鑑` を開く
2. 名前から図鑑を生成する
3. 既存図鑑と同じ名前でもう一度生成を試す
4. 図鑑詳細を開く

期待結果:

- 生成中は経過秒が表示される
- 生成中/失敗時は確認待ちにも表示される
- 同じ植物名は上書きせず、既存図鑑がある旨を表示する
- 基本的な特徴、見た目の特徴と魅力、手入れメモ、生成JSON、生成時間が表示される
- 設定画面のログに図鑑生成履歴が残る

## 7. 図鑑詳細と観察履歴

手順:

1. 図鑑詳細を開く
2. 関連写真と観察履歴を確認する
3. 図鑑を再生成する
4. 図鑑を削除する
5. 観察詳細から図鑑を再生成する

期待結果:

- 関連写真が最大12枚表示される
- 観察履歴から観察詳細へ移動できる
- 図鑑だけ削除され、観察は残る
- 図鑑がない観察から手動で図鑑を再生成できる

## 8. バックアップと復元

手順:

1. `バックアップ` を開く
2. ZIPを書き出す
3. 別ブラウザプロファイル、またはデータを消した状態でZIPを読み込む
4. 観察、図鑑、画像、設定、ログを確認する

期待結果:

- ZIPを書き出せる
- 読み込み後に観察、図鑑、画像が戻る
- バックアップ操作ログが残る
- 件数が大きくずれない

## 9. オフライン閲覧

手順:

1. いくつか観察と図鑑を作る
2. 機内モードにする
3. ホーム画面アイコンから起動する
4. 観察一覧、図鑑一覧、詳細画面を開く

期待結果:

- 保存済みデータを閲覧できる
- AI呼び出しが必要な操作は安全に失敗または抑止される
- オフライン状態がヘッダーに表示される

## 10. 確認時に記録すること

- Android機種名
- Androidバージョン
- Chromeバージョン
- 使用モデル
- 成功した操作
- 失敗した操作
- 設定画面のログ内容
- バックアップZIPが作成できたか

## 判定

最低限、以下が通れば実機確認可能な段階とする。

- PWAインストール
- APIキー保存
- 画像1〜3枚の観察追加
- 観察解析
- 図鑑生成
- 強制停止
- バックアップ書き出し
- ログ確認
