# AI-Plantgraphy PWA 画面ワイヤー

## 1. 目的

本書は、`C:\Users\sgmxk\Desktop\AI\repos\local\AI-Plantgraphy-PWA\docs\SPECIFICATION.md` を画面単位に落とし込んだ簡易ワイヤーを定義する。

実装前に、各画面の役割、主要UI、ボタン、状態差分をそろえることが目的である。

## 4. ホーム

### 4.1 目的

- 直近観察と図鑑導線を見せる
- 初回導入後の起点にする

### 4.2 要素

- ヒーロー
  - アプリ名
  - 一言説明
- CTA
  - 観察を追加
  - 図鑑を見る
- 最近の観察
- 確認待ち件数

### 4.3 ワイヤー

```text
+--------------------------------------------------+
| Header                                           |
+--------------------------------------------------+
| Hero                                             |
|  AI-Plantgraphy PWA                              |
|  [観察を追加] [図鑑を見る]                       |
+--------------------------------------------------+
| 最近の観察                                        |
|  [カード] [カード] [カード]                      |
+--------------------------------------------------+
| 確認待ち                                          |
|  3 件 -> [確認待ちを見る]                        |
+--------------------------------------------------+
```

## 7. 観察詳細

### 7.1 目的

- 解析結果を確認し、必要なら修正・再解析・停止・削除する

### 7.2 要素

- ヒーロー
- 写真ストリップ

- タイマー
- 解析結果
- 候補
- 特徴
- 不確実な点
- 生JSON
- アクション

### 7.3 pending 状態で必要なボタン

- 強制停止

### 7.4 analyzed / needs_review / analysis_failed で必要なボタン

- 手動修正
- 再解析
- 図鑑生成
- 削除

## 13. 状態別 UI ポリシー

### 13.1 解析中

- 経過秒を必ず表示
- 停止ボタンを同じ画面に置く

### 13.2 失敗時

- 赤系ステータス
- 再解析ボタン
- エラー理由表示

### 13.3 既存図鑑あり

- 新規生成の完了表示にしない
- 「既存の図鑑があります」と明示
- 既存詳細へ誘導

### 13.4 曖昧で作成不能

- 「別名や正式名でもう一度試してください」
- ユーザーが次に試す行動が分かる文言にする

## 14. 実装順に対応する画面優先度

- 観察一覧
- 観察詳細

### 優先度 B

- 図鑑一覧
- 図鑑詳細

### 優先度 C

- ホーム
- 確認待ち
- バックアップ / 復元

## 15. 実装メモ

- 既存 HTML のカード構造や情報配置は参考にしてよい
- ただし React コンポーネントとして再構築する
- スタイルは既存の落ち着いた配色をベースにしてよいが、PWA として操作領域を広めに取る

本ワイヤーは高精細なデザイン仕様ではなく、画面責務と構成要素を揃えるための実装用ワイヤーである。
