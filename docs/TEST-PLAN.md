# AI-Plantgraphy PWA テスト計画

## 1. 目的

本書は、`C:\Users\sgmxk\Desktop\AI\repos\local\AI-Plantgraphy-PWA\docs\SPECIFICATION.md` と `C:\Users\sgmxk\Desktop\AI\repos\local\AI-Plantgraphy-PWA\docs\ARCHITECTURE.md` に基づいて、PWA の受け入れ条件を満たすための検証計画を定義する。

## 2. テスト方針

- ロジックは自動テストで守る
- PWA の導入導線は手動確認を含める
- Android 実機での確認を重視する
- AI 応答は完全固定ではなく、壊れ方に強いことを検証する

## 6. 受け入れシナリオ

### 6.1 初回導入

手順:

1. URL を開く
2. PWA をホーム画面に追加する
3. API キーを入力する
4. アプリを再起動する

期待結果:

- 設定が保持される
- 再入力が不要
- ホーム画面アイコンから起動できる

### 6.2 観察追加

手順:

1. 画像を 1〜3 枚選ぶ
2. 観察を保存する
3. 一覧へ戻る

期待結果:

- 画像が保存される
- 観察が一覧に出る
- サムネイルが表示される

### 6.3 AI 解析

手順:

1. 観察追加直後に解析開始
2. 進捗表示を見る
3. 完了後に詳細へ遷移

期待結果:

- `queued` → `analyzing` → `analyzed` / `needs_review` / `analysis_failed`
- 経過秒が表示される
- JSON 結果が保存される

### 6.4 強制停止

手順:

1. 解析中に強制停止ボタンを押す

期待結果:

- リクエストが中断される
- 状態が `analysis_failed` になる
- 停止理由が保存される

### 6.5 図鑑自動生成

手順:

1. 高信頼の観察を完了させる

期待結果:

- 図鑑が生成される
- 図鑑一覧に出る
- 基本特徴、見た目、手入れメモが埋まる

### 6.6 名前から図鑑生成

手順:

1. 和名だけを入力する
2. 図鑑生成を押す

期待結果:

- 学名が十分確定できた場合のみ生成
- 生成中は経過秒が出る
- 完了時は詳細へ移動

### 6.7 名前から図鑑生成の曖昧ケース

手順:

1. 曖昧な和名を入力する
2. 図鑑生成を押す

期待結果:

- 誤生成しない
- 「別名や正式名でもう一度試してください」と出る

### 6.8 既存図鑑の重複検知

手順:

1. 既存図鑑がある和名を入力する
2. 図鑑生成を押す

期待結果:

- 新規生成しない
- 「既存の図鑑があります」と出る
- 既存詳細へ移動する

### 6.9 図鑑削除

手順:

1. 図鑑詳細で削除する

期待結果:

- 図鑑が消える
- 観察は残る
- 観察から図鑑を再生成できる

### 6.10 エクスポート / インポート

手順:

1. 観察と図鑑をいくつか作る
2. ZIP をエクスポートする
3. データを消す
4. ZIP をインポートする

期待結果:

- 観察、図鑑、画像、設定が戻る
- 件数が一致する

### 6.11 オフライン閲覧

手順:

1. いくつかデータを作る
2. 機内モードにする
3. アプリを再起動する

期待結果:

- 一覧が開く
- 詳細が見られる
- AI 呼び出し系は抑止される

## 7. 自動テスト詳細

### 7.1 ドメインロジック

- 観察結果 JSON の正規化
- candidate の上位候補昇格
- visible features の整形
- 不確実メモ生成
- profile の欠落補完

### 7.2 図鑑生成ロジック

- 和名だけで学名推定成功
- 学名推定失敗で生成停止
- 既存図鑑ありで生成停止
- 手入れメモ欠落時の補完

### 7.3 ストレージ

- observation CRUD
- plant CRUD
- image 保存/読込
- export/import round-trip

## 8. 非機能テスト

### 8.1 性能

- 画像3枚追加時にUIが固まりすぎない
- 一覧100件でも表示可能
- 解析中にUI応答が失われない

### 8.2 容量

- 画像圧縮後の容量確認
- 100件規模での IndexedDB 使用量確認

### 8.3 回復性

- 解析途中でタブを閉じた場合
- 解析途中でネットワーク切断した場合
- インポート途中失敗時のロールバック

- Unit Test が全件成功
- Integration Test が全件成功

- Android 実機で名前から図鑑生成成功

- エクスポート/インポート成功
